The project file

[labels]
list = ["needs-data", "good-first-issue", "breaking", "security"]
descriptions = { needs-data = "waits for a figure from the domain" }

[labels.colors]
needs-data = "amber"
breaking = "red"

A colon or a kind in a label is refused (config.Check). Settings › Labels › Send to GitHub creates them there; Adopt writes [labels.colors] from GitHub’s.
