Create a branch: Create, or copy the commands

Decision 4, built both ways: the plus proposes the next name in the issue’s folder, editable; Create has git-board run git branch --no-track and git push -u origin (loopback and the board’s own page only; the checkout never switches); Copy the commands for whoever prefers their own terminal.

Opened

Create a branch

In the issue’s folder, from origin/dev: git-board makes it and pushes it to origin, your checkout stays as it is. Or run it yourself:

git switch -c test/2771/3-research-facilities origin/dev
git push -u origin test/2771/3-research-facilities

The name proposed by [branches] name from the server’s suggestion and the branches it lists; the start is origin’s default branch. No input takes the focus: the panel does.
