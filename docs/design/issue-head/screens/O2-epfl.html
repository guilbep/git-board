What the skill changes in the drawer

Read in its order: AGENTS.md, README.md, the examples, then the tokens and css/. Every size here is rem or a token, every color a token, every icon Feather.

Rule (AGENTS.md, README.md)In the drawerSee it
Tokens only: no hex, no pxSizes in rem or var(--space-*); colors var(--fg), var(--warning-bg)… git-board's value colors (purple, pink) are data from the project file: they sit in a token file beside EPFL's, as the system asks for a value it lacks.
Feather, the primary UI iconsgithub, gitlab, bell, bell-off, git-branch, git-pull-request, git-merge, upload-cloud, download-cloud, refresh-cw, cloud-off. They replace the ✓ ✗ ● characters of today's Development section. The value marks (status, prio, kind) stay git-board's own: Feather has none, and EPFL keeps custom glyphs for that case.
Borders, not shadows; a shadow only on dropdowns and modalsPosts and chips are flat with 1px borders. Only the popovers carry var(--shadow).
Tight radii, pills only for badgesChips, buttons, avatars: 2px. Pills: the forge's count and the tab counts.23
Hover changes color, never liftsIcon buttons and values turn red, as EPFL links and tags do; buttons fill gray-100.
Focus: 2px outline, 2px off, hue-matchedRed-dark on what turns red, gray-600 on neutral buttons, each PR state in its own text color.
Disabled: gray-100 fill, gray-300, opacity 1"Merge into dev" until GitHub says it can.
Signature: a red dot under the active nav itemUnder the active tab, instead of a red underline.
Suisse Int'l, Arial the fallbackThe font loads on *.epfl.ch only. On claude.ai it falls back to Arial, as the skill expects.
