The fields line, and one editor per value

The line under the title (headfields.ts, IssueHead.vue): the status first, “by #N” for a blocked-by, then assignee, prio, sprint and kind when the project has them, else the first four; the other fields set count as +N more. A value opens its own dense editor (FieldEditor.vue); +N more lists every field, a row each, opening its editor in place (FieldPanel.vue). No input takes the focus by itself.
